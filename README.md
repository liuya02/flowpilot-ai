# FlowPilot AI

一个面向产品与项目管理、人力资源与组织管理的双工作台 AI 流程助手。

FlowPilot AI 不替代专业判断。它通过固定的输入表单、结构化结果和人工核验清单，帮助用户把零散材料转换成可以继续执行的工作成果。

## 当前版本

这是可交互的前端 MVP，已经支持：

- 产品与项目管理工作台：需求分析、PRD、任务拆解、会议行动、上线复盘等任务入口。
- 人力资源与组织管理工作台：业务洞察、人力规划、解决方案、员工关系、人才盘点与组织诊断等任务入口。
- 选择任务、填写材料、载入示例、生成结构化结果。
- 产品完整工作流：需求分析 → PRD → 任务拆解 → 上线检查与复盘。
- HR 完整工作流：业务理解 → 业务问题诊断 → 人力解决方案 → 人才盘点或组织诊断；解决方案阶段支持双分支选择。
- 核心任务拥有各自的专业交付物：需求清单、PRD、执行计划、上线复盘表、业务理解卡、五维诊断、解决方案组合、人才行动和组织优化计划。
- 专业交付表可以逐格编辑、保存版本、导出 Markdown，并在核验后连同事实依据一起带入下一阶段。
- 每次流转都要求完成人工核验，并自动带入已确认事实、分析、待确认项和约束。
- 明确区分事实、分析、假设、风险和下一步。
- 生成结果可直接编辑、增删条目；编辑后需要重新完成人工核验。
- 输入和结果会自动保存为浏览器本机草稿；同一工具可建立多份独立草稿，并在草稿中心统一继续或删除。
- 每次 AI 生成会自动形成版本，输入页和结果页也可手动保存版本；每份草稿最多保留最近 12 个版本并支持恢复。
- 每条连续工作链拥有独立的项目名称；进入下一阶段时会继承同一项目身份，已有项目也可以随时改名。
- 项目驾驶舱按项目汇总当前阶段、工作链进度、行动项、风险、待确认事项和阶段记录，并可一键回到当前阶段。
- 驾驶舱可直接维护负责人、截止时间、里程碑、阻塞事项和项目风险；状态会自动判断为正常推进、临近截止、存在阻塞或已完成。
- 驾驶舱支持一键导出完整项目 Markdown，按阶段顺序汇总项目管理信息、专业交付表、事实、分析、风险和下一步。
- 顶部“教程”提供产品项目与人力组织两套完整案例，一键新建独立项目，并预填第一阶段材料和可操作的项目计划。
- 教程项目会保存完成进度，任务页与结果页显示当前阶段；重新打开教程可继续原项目，也可以重新开始练习。
- 输入信息过少时先给出补充建议，也允许使用现有信息继续；实时生成失败时保留本地模板结果并提供 DeepSeek 重试入口。
- 人工核验清单、结果复制和 Markdown 下载。
- 通过项目服务端代理调用 DeepSeek，返回事实、分析、假设、风险和下一步等结构化结果。
- 桌面端与手机端响应式布局。

生成请求会由项目服务端转发至 DeepSeek；API 不可用时自动使用浏览器本地模板兜底。草稿保存在当前浏览器的 `localStorage` 中。

## 本地运行

```bash
npm install
npm run dev
```

首次运行前复制环境变量示例并填写 DeepSeek Key：

```bash
cp .env.example .env.local
```

`DEEPSEEK_API_KEY` 只由本地开发代理和部署端 Worker 读取，不会进入前端构建产物。部署时需要在托管环境中配置同名服务端密钥。

生产构建：

```bash
npm run build
```

## 数据与隐私

- 请勿在公开演示中输入真实工资、绩效、身份证明、健康信息或劳动争议材料。
- 人力资源相关示例必须使用虚构或彻底匿名的数据。
- 使用共用电脑后，请从首页清除本机草稿。
- 任务输入会发送给 DeepSeek 以生成结构化结果，请根据实际数据政策决定可以输入的内容。
- AI 生成内容只用于辅助分析，高影响结论必须由授权人员复核。
